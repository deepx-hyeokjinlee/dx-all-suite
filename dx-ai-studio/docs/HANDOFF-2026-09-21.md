## 줌 사각지대에서 진짜 결함이 하나 나왔다 (고쳤음)

처음 `body.style.zoom` 으로 재니 탭 오버플로 버튼도 닿지 않는 것처럼 보였다.
**그것은 측정 착시였다** — style.zoom 은 resize 를 일으키지 않아 탭 오버플로
계산이 갱신되지 않는다. 실제 줌에 해당하는 좁은 뷰포트로 다시 재니 탭은
정상이었고, **툴바만 남았다.**

**진짜 결함**: 512px 폭(≈ 200% 줌)에서 `.dx-toolbar` 가 화면 밖으로 밀려
`◑`(테마)와 `⚙️`(설정) 버튼을 **누를 수 없었다.**

```
.dx-shell-header       505/456   <- 49px 넘침
.dx-shell-body         overflow-x: hidden   <- 잘라냄
=> 문서 가로 넘침 0 이라 줌 감사는 통과
```

원인은 `.dx-shell-header-left` 와 `-right` 가 **둘 다 `flex-shrink:0`** 이라
헤더가 줄지 않은 것. 왼쪽(모듈명·경로)이 양보하도록 고쳤다 — 말줄임으로 줄어도
되는 쪽이고, 오른쪽은 눌러야 하는 컨트롤이다.

셸은 여덟 모듈이 공유하므로 **여덟 모듈 전부** 512px 에서 검증했다(11건 통과).
